# Copiô

Backup de cartão de memória para fotógrafos e filmmakers, por [Sales Wed.](https://www.instagram.com/saleswed_/)

Coloque o cartão e o Copiô abre sozinho. Ele separa fotos, vídeos e áudios, põe a câmera e quem captou no nome de cada arquivo (`MVI_1000.MP4` → `MVI_1000_CanonR8_Sales.MP4`), nunca sobrescreve nada e confere cada cópia com o original.

## Baixar

Página de download: https://apps.weddingflow.com.br/copio/

Ou direto pelas [versões](../../releases/latest):

- **Mac** (macOS 11+, Apple Silicon e Intel): `Copio.dmg`
- **Windows** (10 e 11): `Copio-Windows.zip`
